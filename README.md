# Lingo

Lingo is a Turkish word-guessing game built with Flutter. Choose a 4-, 5-, 6-,
or 7-letter game, enter a Turkish word with the on-screen keyboard, and use the
tile colors to solve the hidden word in six guesses.

## Run the app

Install the Flutter stable SDK, then run:

```shell
flutter create --project-name lingo --org com.dmw2121 --platforms android .
flutter pub get
flutter run
```

The Android platform files are generated by the release workflow and are not
checked in.

Run the unit tests and static checks with:

```shell
flutter test
flutter analyze
```

The Android release workflow runs for version tags such as `v1.0.0` and
publishes the release APK on that GitHub release.

## Word list attribution

The bundled 4,000-word subset is selected by frequency from the Turkish
`small_tr` word list in [wordfreq](https://github.com/rspeer/wordfreq), at
revision `912caf64b657478d1dff1138efdc078947d54bb1`. It contains exactly 1,000
lowercase Turkish-alphabet entries of each length from four through seven.
The source reports frequency data compiled from multiple corpora and licenses
its data under [Creative Commons Attribution-ShareAlike 4.0
International](https://creativecommons.org/licenses/by-sa/4.0/). The bundled
subset and adaptations are made available under that same license. See
`assets/WORDLIST_ATTRIBUTION.md` for attribution and included license notices.

This frequency-based list includes common inflected forms and names; it is not
a dictionary of definitions or an official Turkish Language Association
wordlist.
